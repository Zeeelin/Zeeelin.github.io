Description of the Project

Foldward is a two-week Unity prototype exploring procedural origami animation. The system responds to player input in real time and supports multiple possible folding outcomes, turning animation behavior into part of the core gameplay.

Role in the Project

Programmer

As part of the five-person team, I programmed the input-driven procedural folding system and explored how multiple animation outcomes could remain readable and responsive. We rapidly prototyped and iterated on the game within a two-week schedule.

Application/Software Used: Unity, C#, Perforce
